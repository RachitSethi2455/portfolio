03 ◐ IN PROGRESS · AI SYSTEMSLLM INFRASTRUCTURE● LIVE DEMO

Cost-Aware Model Router

Most LLM requests don't need the most expensive model. This router sends each request to a cheap or an expensive model, computes exact answers in a sandbox instead of letting the small model guess, and reports every result with its sample size and a 95% interval.

what broke along the wayThe offline tests passed from day one. Running against real models still found these — each now fixed and covered by a test.
  1. Thinking models ate the output budget — a 1,024-token limit came back as a 40-token fragment.
  2. Hidden reasoning tokens weren't billed, so the large model looked about 25× cheaper than it was.
  3. Failures looked like successes — both tiers failing still returned 200 with an empty answer.
  4. The .env file was never loaded, and a stale system key silently overrode it.
